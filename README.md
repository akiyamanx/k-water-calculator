# K-Water 純水装置 設計・運用・早見計算機

洗車場などの純水装置（活性炭→RO→EDI）の設計・運用を助ける単一HTMLの計算機です。`index.html` をブラウザで開くだけで動きます（サーバー不要・インストール不要・入力データが外部へ送られることもありません）。

## 6つのタブ

| タブ | 内容 |
|---|---|
| 設計 | 原水水質（イオン分析）からスケーリングリスク・最大許容回収率・前処理を提案 |
| 循環水 | 機種公式マトリクスから循環水量の基準値を照合 |
| RO 4040 | 膜本数・圧力・水温・TDSから透過水量を推算。本数ごとの升目表 |
| EDI XL | EDIモジュールの水量バランス・CIP条件・全機種カタログ |
| 受水槽 | 1日の水量収支とタンク容量の検討。バケツ計測の換算つき |
| 調整ガイド | ROの除去率・必要圧力・EDIの抵抗値から調整方向と手順を提示 |

## 使い方

1. `index.html` をダウンロード
2. ブラウザで開く
3. タブを選んで条件を入力

## 注意

この計算機はメーカー公称値・公式マトリクスからの**推算**です（個体差・膜の経年で±10〜20%ずれます）。実際の調整は計器の実測値で確認し、薬品洗浄や改造はメーカー・導入業者の手順に従ってください。
